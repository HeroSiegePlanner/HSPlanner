## Development
- Renamed the app, executable and installers to HSPlanner (without Native); update discovery uses the packaging checksum manifest to distinguish releases from archived Tauri installers.
- Made the native workspace independent of the ignored local Tauri archive; retired legacy CI/release workflows and excluded generated builds and review output from Git.
- Runeword tooltips now group item bonuses under Implicit before Granted Skill Effects and socket bonuses, matching ordinary item tooltips; empty granted-skill descriptions no longer add a blank line.
- Added the Ent's Blessing runeword (Io + Pul, Armor) and a Belt slot for the mercenary loadout. Runewords can now grant skills (`skillBonuses`), read everywhere item-granted skills are: skill ranks, mercenary auras, tooltips and aura toggles. Angel's Vibrance Aura got its passive stats (5% [+2/level] All Resistances, 45 [+8/level] Life and Mana Replenish) and its granted-skill name now matches the item key, so shields with the aura resolve it too.
- Fixed sidebar stat rows overflowing horizontally: numeric ranges stay intact and raw diminishing-return values sit below their effective values in one aligned column.
- Fixed stat labels in the left stats sidebar wrapping one letter per line (for example Attack Speed) when a long value plus its diminished raw value did not fit: labels no longer break mid-word and values drop to a right-aligned second line instead.
- Ported Suggest Nodes to the native Incarnation tree (`crates/planner/src/tree_suggest.rs`): a Suggest toolbar panel with a 1–200 node budget slider runs the engine's greedy DPS optimizer (`suggest_engine`, now enabled for the native build) on a background worker with cancel and progress, highlights the proposed nodes on the graph as a preview, lists the sequence with Base/Final/Gain DPS and unsupported mod lines, and Apply allocates them in the suggested order. Results clear whenever the document changes.
- Native in-app updates (`crates/app/src/update.rs`): the footer version control checks the latest GitHub release on startup and on demand, ignores legacy Tauri releases, and offers Install and restart. macOS downloads the DMG, verifies GitHub's sha256 digest, swaps the running `.app` bundle in place and relaunches; Windows runs the downloaded NSIS installer; Linux opens the release page. Release assets keep the `HSPlanner_` prefix produced by `packaging/packager.json`.
- Fixed a runaway memory spike and freeze when moving between subskill nodes: the leaving tooltip (kept open 500ms as hoverable) and the new one re-requested the next-rank preview against each other in an endless loop, spawning background calculations every cycle. The subtree now owns the re-request after allocation/progression changes; tooltips only refresh their rank. Cursor tooltips are now an own element (`crates/ui/src/tooltip.rs`) instead of gpui's tooltip layer: they stay open through clicks and disappear the moment the mouse leaves, without gpui's 500ms hoverable grace period.
- All native tooltip triggers now show immediately and follow the live cursor, including controls, items, subskills and stat sources.
- Fixed subskill tooltip wrapping and section heights; tooltips remain open during point allocation/removal and refresh the next-rank preview after changes. Long tooltips can scroll within the window.
- Redesigned skill damage breakdowns as compact, collapsible calculation summaries with aligned values, neutral modifiers omitted, and equations, exact values and stat sources available on demand.
- Removed gem tier labels from socket pickers and equipped sockets; stash rings now offer explicit Ring 1 / Ring 2 destinations.
- Expanded native skill Stats breakdowns with engine-recorded inputs, per-source synergies, formulas, more multipliers, conversions, resistances, critical averaging, projectile counts, attack/cast rates, procs, ailments and the final DPS calculation. Build-stat inputs open their source details. Existing serialized calculation results remain unchanged.
- Removed pagination from all native gear editor pickers; sockets, runewords, skills, elements and classes now use one continuous scrollable list, like the Tauri reference.
- One definition of the native button look (`button_look` / `planner_button` in `crates/ui/src/controls.rs`, tones Neutral / Primary / Danger): editor actions, section header actions, icon buttons, item/stash tabs, Stats filters, top bar, library toolbar and tree toolbar all use it (Inter, sentence case, hairline border, rounded corners). `planner_style` on a Button now applies the same look, so surfaces with their own colours call `.custom(...)` after it.
- Mods deleted through Text Edit now stay hidden in item text, tooltips and roll controls; their zero overrides remain in the save to suppress the authored base stat.
- Added native item Text Edit with human-readable affixes, forged modifiers, stars, sockets, skill bonuses and augments; live line validation, searchable custom-stat insertion and isolated Save/Cancel before applying the gear draft.
- Added roll sliders and current/ranged values to forged Satanic Crystal modifiers; choosing a roll pins the value used by calculations and native saves.
- Grouped ordinary affix tiers into one picker entry; equipped affixes now use a value slider that selects the matching tier and roll, including overlapping ranges and negative modifiers. Unholy pool effects remain independent.
- Refined native affix, satanic crystal and angelic augment pickers with compact reference-sized windows, prefix/suffix groups, type columns, tier badges and continuous scrolling. Unholy affixes use their own accent and picker title.
- Native gear pickers for sockets, runewords, affixes, forge crystals, angelic augments, random skills, subskills and classes share the item picker row design: sprite (socketables, augments, skills), tone-coloured name, mono detail, hover, and a highlight on the current choice. Augment rows list their top-level stats instead of a fixed label; the list header, search field and pagination footer match the Items/Stash picker.
