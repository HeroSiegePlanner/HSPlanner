## Interface

- New build opens a dialog to pick the name, class and level, and files the build in the folder you are viewing.
- Import opens a dialog that fills in a build code from the clipboard, previews its class, level and contents, and lets you name the build before it is saved to the folder you are viewing.
- Share codes carry the build's name, so an imported build keeps it.
- Share opens a window with two choices: copy the build code, with or without the stash, or store the build on hsplanner.app and copy its link.
- Import accepts hsplanner.app links as well as build codes.
